# Agro Shipment Tracker
A Next.js application that simulates shipment tracking for agricultural products.

The project demonstrates modern Next.js concepts including:
- App Router
- Server Components
- Client Components
- Server Actions
- Route Protection
- Middleware
- Optimistic Updates
- Suspense and Loading States
- Form Handling
- Revalidation

## Features
- Shipment tracking workflow
- Progress history
- Undo tracking changes
- Admin dashboard
- Protected routes
- Login/logout functionality
- Delivery log management
- Responsive design

## Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
